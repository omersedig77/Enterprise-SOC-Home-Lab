# Incident Severity Classification

| Severity | Description | Example |
|----------|-------------|----------|
| Critical | Active compromise with significant impact | Ransomware, Credential Dumping |
| High | Confirmed malicious activity requiring immediate investigation | Reverse Shell, Successful Brute Force |
| Medium | Suspicious activity requiring analyst review | Multiple Failed Logins |
| Low | Informational events with minimal risk | Single Failed Login |
| Informational | Expected system activity | Service Start, Scheduled Task |
