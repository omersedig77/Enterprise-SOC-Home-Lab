| Brute Force | T1110 |
| Ingress Tool Transfer | T1105 |
| Command and Scripting Interpreter | T1059 |
| Registry Run Keys | T1547.001 |
| Cron | T1053.003 |
| Unquoted Service Path | T1574.009 |
| LSASS Memory | T1003.001 |
| Exfiltration Over C2 | T1041 |
