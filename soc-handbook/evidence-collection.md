# Evidence Collection

Evidence should be collected before containment whenever possible.

## Endpoint Evidence

- Windows Event Logs
- Sysmon
- Linux Logs
- Running Processes
- Registry Changes
- Scheduled Tasks

## Network Evidence

- Firewall Logs
- DNS Queries
- Network Connections

## SIEM Evidence

- Alerts
- SPL Searches
- Dashboards
- Correlation Searches

## Documentation

Record:

- Date and Time
- Source
- Event IDs
- Screenshots
- Investigation Notes
