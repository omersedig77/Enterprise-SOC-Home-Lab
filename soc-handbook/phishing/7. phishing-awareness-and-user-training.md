# Phishing Awareness and User Training

## Overview

Technology alone cannot prevent every phishing attack.

Attackers frequently target employees because humans are often the easiest entry point into an organization.

A strong phishing defense strategy combines:

- Security technology
- User awareness
- Regular training
- Phishing simulations
- Fast reporting
- Continuous improvement

The goal of security awareness is not only to prevent users from clicking malicious content but also to create a culture where employees quickly report suspicious activity.

---

# Why Phishing Awareness Matters

Phishing remains one of the most common initial access techniques because attackers exploit:

- Trust
- Urgency
- Fear
- Curiosity
- Authority
- Human mistakes

Examples:

```
"Your account will be disabled today"

"Invoice attached - payment required"

"CEO requesting urgent transfer"

"Password expires immediately"
```

These messages attempt to force users into making fast decisions without verification.

---

# Common Phishing Psychological Techniques

---

# 1. Urgency

Attackers create pressure.

Examples:

```
Your account will be deleted in 30 minutes.

Immediate action required.
```

Purpose:

Prevent the user from thinking carefully.

---

# 2. Fear

Attackers create panic.

Examples:

```
Suspicious login detected.

Your account has been compromised.
```

User behavior:

- Clicks link
- Enters credentials
- Ignores security procedures

---

# 3. Authority Impersonation

Attackers pretend to be:

- CEO
- Manager
- IT department
- Bank
- Government organization

Example:

```
From:

CEO@example.com


Message:

Send the confidential document immediately.
```

---

# 4. Curiosity

Examples:

```
Salary Report Attached

Confidential Document

Employee Bonus List
```

The attacker wants the user to open the attachment.

---

# 5. Reward

Examples:

```
You won a gift card.

Claim your reward now.
```

---

# Common Phishing Attack Types

---

# Email Phishing

The most common type.

Example:

```
Fake Microsoft password reset email
```

Goal:

- Steal credentials
- Deliver malware
- Redirect users to fake websites

---

# Spear Phishing

A targeted phishing attack against specific individuals.

Attackers research:

- Employee names
- Job roles
- Company information
- Projects

Example:

Target:

Finance employee

Email:

```
Updated invoice attached.
```

---

# Business Email Compromise (BEC)

Attackers impersonate executives or trusted partners.

Common goals:

- Financial fraud
- Wire transfers
- Sensitive information theft

---

# Whaling

A phishing attack targeting executives.

Targets:

- CEO
- CFO
- Directors

---

# Smishing

SMS-based phishing.

Example:

```
Your package delivery failed.

Click here to reschedule.
```

---

# Vishing

Voice phishing.

Attackers use phone calls to:

- Collect credentials
- Impersonate support teams
- Request payments

---

# QR Code Phishing (Quishing)

Attackers use QR codes to redirect victims.

Example:

```
Scan QR code to verify account
```

The QR code redirects to:

- Fake login pages
- Malware websites

---

# How Employees Should Identify Phishing Emails

Employees should check:

---

# Sender Address

Question:

Does the sender match the organization?

Example:

Legitimate:

```
support@microsoft.com
```

Suspicious:

```
support@microsoft-security-login.com
```

---

# Subject Line

Suspicious examples:

```
URGENT!!!

Action Required Immediately

Final Warning

Account Will Be Closed
```

---

# Greeting

Suspicious:

```
Dear Customer
```

Instead of:

```
Dear John Smith
```

---

# Email Content

Look for:

- Spelling mistakes
- Strange formatting
- Unusual requests
- Pressure tactics
- Requests for passwords

---

# Links

Before clicking:

Check:

- Domain name
- Spelling
- HTTPS
- Destination

Example:

Fake:

```
login-microsoft-security.com
```

Real:

```
login.microsoftonline.com
```

---

# Attachments

Be careful with:

```
.exe

.scr

.js

.zip

.docm

.xlsm
```

Especially when unexpected.

---

# Simulation Metrics

Important measurements:

---

# Click Rate

Percentage of users who clicked the phishing link.

Formula:

```
Clicked Users / Total Users × 100
```

Example:

```
20 users clicked

500 users received email


Click Rate:

4%
```

Lower is better.

---

# Reporting Rate

Percentage of users who reported the phishing email.

Formula:

```
Reported Emails / Delivered Emails × 100
```

Higher is better.

---

# Credential Submission Rate

Percentage of users who entered credentials.

Formula:

```
Credential Submissions / Delivered Emails × 100
```

Lower is better.

---

# Repeat Failure Rate

Measures users who repeatedly fail simulations.

Used to identify:

- Additional training needs
- High-risk departments

# Security Training Topics

Employees should understand:

## Password Security

Teach:

- Never share passwords
- Use MFA
- Avoid password reuse


---

## Email Verification

Teach:

- Verify unusual requests
- Contact sender through another method


---

## Attachment Safety

Teach:

- Do not open unexpected files
- Verify before downloading


---

## Link Safety

Teach:

- Hover over links
- Check domains
- Avoid shortened URLs

# Common Employee Mistakes

Examples:

```
Clicking unknown links

Opening unexpected attachments

Ignoring sender mismatch

Trusting urgent requests

Reusing passwords

Entering credentials into unknown websites
```

---

# What Employees Should Do After Clicking a Phishing Link

Immediately:

```
1. Disconnect from network if necessary

2. Report the incident

3. Change password if credentials entered

4. Contact IT/SOC

5. Do not delete evidence
```

---

# What Employees Should NOT Do

Avoid:

```
Deleting the email

Continuing to use compromised credentials

Ignoring the event

Trying to investigate malware themselves
```

# Key Takeaways

Phishing defense requires both technology and human awareness.

A successful security awareness program helps employees:

- Recognize phishing attempts
- Avoid unsafe actions
- Report suspicious activity quickly
- Support SOC investigations

Employees are an important part of the security defense strategy, and effective awareness programs reduce the success rate of phishing campaigns.
