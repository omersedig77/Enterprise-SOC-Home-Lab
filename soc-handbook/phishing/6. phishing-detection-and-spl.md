# Phishing Detection and Splunk Investigation

## Overview

Phishing attacks are not only investigated through email analysis.

A SOC analyst must also detect the activity generated after a user interacts with a phishing email.

A successful phishing attack can generate:

- Network connections
- Browser activity
- Credential submission attempts
- Malware execution
- PowerShell activity
- Suspicious child processes
- Persistence mechanisms
- Command and Control communication

In a SOC environment, phishing detection requires correlation between:

- Email security telemetry
- Endpoint logs
- Sysmon events
- Firewall logs
- DNS logs
- Proxy logs
- Authentication logs

# Sysmon Detection

## Event ID 1 - Process Creation

Look for:

```
ParentImage:

WINWORD.EXE


Image:

powershell.exe
```

---

Example SPL:

```spl
index=sysmon EventCode=1
| search ParentImage="*WINWORD.EXE"
OR ParentImage="*EXCEL.EXE"
OR ParentImage="*POWERPNT.EXE"
| search Image="*powershell.exe"
OR Image="*cmd.exe"
OR Image="*wscript.exe"
| table _time Computer User ParentImage Image CommandLine
```

---

# Sysmon Event ID 1 Detection

Example:

```spl
index=sysmon EventCode=1
Image="*powershell.exe"
(CommandLine="*EncodedCommand*"
OR CommandLine="*DownloadString*"
OR CommandLine="*Invoke-WebRequest*")
| table _time Computer User ParentImage CommandLine
```

```spl

"malicious-domain.com"
```

# Key Takeaways

Phishing detection requires visibility beyond the email itself.

A mature SOC combines:

- Email analysis
- Endpoint telemetry
- Sysmon monitoring
- Network visibility
- Threat intelligence
- User activity analysis

The objective is not only to detect phishing emails but to identify the complete attack chain from initial delivery to compromise.
