# 📘 SOC Analyst Handbook

## Overview

The SOC Analyst Handbook is a collection of operational procedures, investigation methodologies, and best practices used throughout this SOC Homelab project.

While the attack simulations and incident investigations demonstrate practical hands-on experience, this handbook documents the standard workflows followed by Security Operations Center (SOC) analysts during day-to-day operations.

The objective of this section is to provide a structured reference for:

- Alert triage
- Incident classification
- Investigation methodology
- Evidence collection
- Threat hunting
- MITRE ATT&CK mapping
- Splunk investigation workflow
- Analyst checklists

These notes are based on industry-standard SOC practices and are intended for educational and defensive cybersecurity purposes.
