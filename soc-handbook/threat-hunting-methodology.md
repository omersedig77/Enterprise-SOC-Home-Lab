# Threat Hunting Methodology

Threat hunting is the proactive search for malicious activity that may not trigger automated alerts.

## Hunting Process

1. Develop a hypothesis.
2. Query available telemetry.
3. Correlate multiple data sources.
4. Validate findings.
5. Document results.
6. Improve detections.

## Data Sources

- Windows Event Logs
- Sysmon
- Linux Logs
- Firewall Logs
- Splunk Dashboards
