# Overview

This detection identifies reconnaissance activity targeting Linux SSH services.

Attackers commonly perform network discovery before attempting exploitation. During reconnaissance, tools such as Nmap may generate repeated connection attempts, invalid SSH requests, protocol errors, or pre-authentication failures.

The detection monitors SSH-related authentication events to identify possible scanning activity against Linux systems.

---

# Detection Objective

The purpose of this detection is to identify:

- SSH service reconnaissance
- Automated scanning activity
- Service discovery attempts
- Early-stage attacker behavior

The detection provides visibility into:

- Source IP address
- Target Linux host
- SSH activity
- Number of suspicious connection attempts
- Scan timeframe

# SPL Detection

```spl
index=linux_logs sourcetype=linux_secure "sshd" ("Connection closed" OR "Bad protocol version" OR "Disconnecting" OR "preauth")

| rex field=_raw "by (?<src_ip>\d+\.\d+\.\d+\.\d+) port (?<src_port>\d+)"
| rex field=_raw "from (?<src_ip>\d+\.\d+\.\d+\.\d+) port (?<src_port>\d+)"
| rex field=_raw "invalid user (?<targeted_user>\S+)"

| rename host as target_system
| rename splunk_server as target_ip

| eval target_port = "22 (SSH)"
| eval targeted_user = coalesce(targeted_user, "None (Pre-auth Scan)")

| stats min(_time) as detection_time, count by src_ip, target_ip, target_system, target_port, targeted_user

| fieldformat detection_time = strftime(detection_time, "%Y-%m-%d %H:%M:%S")

| eval threat_score = if(count > 5, "Medium - Reconnaissance Scan", "Low - Normal Noise")

| table detection_time, src_ip, target_ip, target_system, target_port, targeted_user, count, threat_score
```
