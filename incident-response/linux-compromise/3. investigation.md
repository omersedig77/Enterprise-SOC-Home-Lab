# Investigation Process

## Step 1 - Alert Review

Reviewed Splunk alerts generated from Linux security monitoring.

---

## Step 2 - Authentication Analysis

Reviewed:

- Failed SSH authentication attempts.
- Successful SSH login events.
- Source IP information.

Evidence source:

/var/log/auth.log

---

## Step 3 - System Activity Analysis

Reviewed:

- System events.
- Cron activity.
- User actions.

Evidence source:

/var/log/syslog

---

## Step 4 - Network Correlation

Firewall telemetry was reviewed to identify:

- Attacker communication.
- Suspicious outbound connections.
- Network activity related to the compromise.

---

## Investigation Result

The investigation confirmed a simulated Linux endpoint compromise involving unauthorized SSH access and persistence.
