# Summary

A simulated attack was performed against the Ubuntu Linux endpoint to validate Linux-focused security detections.

The attack simulated a complete compromise lifecycle including:

- Reconnaissance
- SSH brute force
- Successful authentication
- Persistence
- Post-exploitation activity
- Data exfiltration behavior

Linux authentication and system logs were collected using the Splunk Universal Forwarder and analyzed through Splunk Enterprise.

---

# Attack Overview

The attacker performed:

1. Port scanning using Nmap.
2. SSH brute-force attack using Hydra.
3. Successful SSH authentication.
4. Cron-based reverse shell persistence.
5. Post-exploitation activities.

---

# Detection

The incident was detected through custom Splunk detections using:

- Linux authentication logs
- Linux system logs
- Kernel logs
- Firewall telemetry

---

# Impact Assessment

Observed attacker activities:

- Unauthorized SSH access.
- Persistence mechanism creation.
- System discovery.
- Suspicious outbound communication.

Detection and investigation completed.
