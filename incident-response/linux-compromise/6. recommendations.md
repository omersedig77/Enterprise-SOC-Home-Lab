# Response Recommendations

## Containment

Recommended actions:

- Disable compromised user accounts.
- Terminate unauthorized SSH sessions.
- Block attacker IP addresses.
- Restrict SSH access.

---

## Eradication

Recommended actions:

- Remove malicious cron entries.
- Delete unauthorized scripts.
- Review user accounts and permissions.

---

## Recovery

Recommended actions:

- Reset affected credentials.
- Validate system configuration.
- Continue monitoring authentication activity.

---

## Lessons Learned

- Authentication logs provided critical visibility.
- Combining host and firewall telemetry improved investigation accuracy.
- Persistence detection is essential after account compromise.
