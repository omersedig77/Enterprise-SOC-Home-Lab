# Response Recommendations

## Containment

Recommended actions:

- Isolate affected endpoint.
- Disable compromised accounts.
- Block malicious source IP addresses.

---

## Eradication

Recommended actions:

- Remove persistence mechanisms.
- Delete malicious files.
- Review scheduled tasks and registry startup entries.

---

## Recovery

Recommended actions:

- Reset credentials.
- Validate system integrity.
- Monitor for repeated malicious activity.

---

## Lessons Learned

- Sysmon significantly improved visibility.
- Correlation between endpoint and firewall logs improved investigation accuracy.
