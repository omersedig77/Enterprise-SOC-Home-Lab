# Response Recommendations

## Containment

Recommended actions:

- Reset affected user credentials.
- Block phishing infrastructure.
- Remove phishing emails from mailboxes.

---

## Investigation Expansion

Recommended actions:

- Search for similar emails.
- Review additional endpoint activity.
- Identify other affected users.

---

## Recovery

Recommended actions:

- Monitor authentication activity.
- Provide user awareness training.
- Continue phishing monitoring.

---

## Lessons Learned

- User interaction telemetry alone is not enough.
- Endpoint telemetry provides additional investigation capability.
- Correlating multiple data sources improves incident analysis.
