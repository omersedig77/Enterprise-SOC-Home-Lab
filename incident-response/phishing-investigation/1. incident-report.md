# Summary

A phishing simulation was conducted using GoPhish to demonstrate a credential harvesting attack lifecycle.

The simulation included:

- Email delivery.
- User interaction.
- Malicious link access.
- Credential submission.

Detection was performed through Windows Sysmon network telemetry collected by Splunk Enterprise.

---

# Detection

The investigation used:

- Sysmon Event ID 3
- Network connection telemetry
- Splunk searches

---

# Impact Assessment

The simulation demonstrated:

- User interaction with phishing content.
- Connection to attacker-controlled infrastructure.
- Potential credential exposure.
