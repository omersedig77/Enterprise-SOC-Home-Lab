# 📚 SOC Incident Response Playbooks

## Overview

This directory contains incident response playbooks developed for the SOC Homelab.

Each playbook provides a structured investigation and response workflow for common security incidents observed during the attack simulations performed within this project.

The playbooks are designed to demonstrate how a SOC analyst can consistently investigate, assess, and recommend response actions based on alerts generated by Splunk Enterprise.

---

## Playbook Structure

Each playbook follows the same format:

- Purpose
- Detection
- Investigation
- Containment Recommendations
- Eradication Recommendations
- Recovery Recommendations
- MITRE ATT&CK Mapping
- Lessons Learned

---

## Available Playbooks

| Playbook | Description |
|----------|-------------|
| Windows RDP Brute Force | Investigation of repeated RDP authentication attempts |
| Linux SSH Brute Force | Investigation of SSH brute-force attacks |
| Reverse Shell | Detection and investigation of reverse shell activity |
| Registry Run Key Persistence | Investigation of Windows persistence mechanisms |
| Linux Cron Persistence | Investigation of cron-based persistence |
| Credential Dumping | Investigation of LSASS dumping and Mimikatz activity |
| Phishing Credential Harvesting | Investigation of phishing campaigns |
| Network Port Scanning | Investigation of reconnaissance activity |

---

> **Note:** These playbooks document recommended SOC analyst procedures. They are based on the simulated attack scenarios performed within this homelab and are intended for educational and defensive cybersecurity purposes.
